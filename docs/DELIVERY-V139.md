# Поставка v1.3.9 — запуск приложения не может остаться невидимым

Дата: 2026-11-20.

## Симптом у пользователя (продолжение истории v1.3.8)

После исправления проверки целостности «Запуск (Windows)» по-прежнему «ничего не делал»: окно командной строки закрывалось, окно приложения не появлялось. Копия проекта при этом в полном порядке (`tools/version.js` — 304/304).

## Диагноз (подтверждён на машине пользователя)

Самый первый запуск (ещё на старой, рассинхронизированной копии) оставил **зависший процесс `electron.exe` без окна** (PID 9344 с дочерними процессами рендера). Приложение берёт блокировку единственного экземпляра (`requestSingleInstanceLock`), поэтому каждый следующий запуск мгновенно и молча завершался, «передавая фокус» невидимому окну первого экземпляра: обработчик `second-instance` звал только `win.focus()`, а спрятанное окно от этого не появляется.

После `taskkill /F /IM electron.exe /T` приложение сразу запустилось (`node node_modules\electron\cli.js .` — планировщик репрайсера стартовал, окно открылось).

Почему окно первого экземпляра не показалось, из сегодняшнего кода не восстановить (это была старая копия), но класс отказа «процесс есть — окна нет — все запуски молчат» теперь закрыт страховками ниже.

## Что сделано (`electron/main.js`)

1. **Повторный запуск показывает окно.** В `second-instance`: если окно существует, но не видимо — `win.show()` перед `restore()`/`focus()`. Зависший без окна экземпляр больше не глушит повторные запуски.
2. **Страховочный показ окна.** Если `ready-to-show` не сработал за 15 секунд (сбой загрузки или рендера), окно показывается принудительно, а событие пишется в журнал. Невидимый процесс-«призрак» больше не образуется.
3. **Журнал ошибок запуска.** Все фатальные ошибки главного процесса (`uncaughtException`, остановка запуска профилей, `did-fail-load` окна) пишутся в `startup-error.log` в каталоге данных приложения (`%APPDATA%\WB Price Manager\`) и, где возможно, показываются диалоговым окном. Молчаливая смерть главного процесса теперь оставляет след, который можно прислать в поддержку.

## Итог проверки

- `npm test` — exit 0 (2067 проверок; синтаксис `main.js` входит в проверку целостности).

## Если симптом повторится на старой версии

Диспетчер задач → завершить все `electron.exe` → запустить снова. Начиная с v1.3.9 повторный запуск сам покажет окно первого экземпляра, а при сбое загрузки окно появится принудительно через 15 секунд; подробности будут в `%APPDATA%\WB Price Manager\startup-error.log`.
