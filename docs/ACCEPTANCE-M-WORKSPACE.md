## Замечания владельца

- Три пункта бокового меню удалены. Цены/скидки, экономика и себестоимость доступны только
  внутри рабочего места репрайсера; сохранены калькулятор, сценарии и старые переходы по товару.
- У всех 12 вкладок единое оформление как у журнала изменения цен.
- Таблица товаров: границы и полосы строк заметнее, больше исходные размеры полей;
  ширина, высота, перестановка колонок/строк, клавиатурные действия, сброс вида.
  «Товар» закреплён; прочие колонки двигаются. Настройки сохраняются отдельно по кабинету.
- Светлая/тёмная тема переключается в шапке и сохраняется локально.
- Ссылка на акцию формируется точно как `https://seller.wildberries.ru/dp-promo-calendar?action=ID`;
  сохранённая ранее главная страница не подменяет её.
- Корень неработавшего выбора файла Electron: плоский ответ `ui:import-file` против ожидаемого
  `res.data`. Приведено к общему контракту, проверена и обратная совместимость старого ответа.
- Импорт: выбор → предпросмотр реальных прочитанных строк → «Сохранить» → видимый состав акции.
  Поддержаны лист-инструкция/преамбула, проценты Excel, кодировки CSV, варианты заголовков,
  пустые shared strings и ограниченная безопасная распаковка ZIP. Ошибочный файл не стирает старый.
- В окне условий «Сохранить», а не «Ввести выбранные»: сохраняются выбор/порог для РП, не цены WB.
  Импорт не включает автоотправку. Участие по текущей цене до СПП/всем размерам/периоду явно
  отделено от подтверждения состава API. Для фиксированного порога файла выход также требует
  пересечения цены; предел шага и запрет изменения базы не обходятся ради ложного успеха.
- НДС 22% выделяется из цены по 22/122. УСН, НДС и годовые взносы ИП разделены; нет плоских 7%
  на всю выручку. Годовой доход/взносы/уменьшение УСН настраиваются в текущем кабинете.
  Старый режим 20% явно архивный; сохранённые данные не переключаются молча.
- При смене налогов предложение становится stale; во время выполняющейся операции смена
  отклоняется до записи. UI показывает ошибку, а не теряет async-исключение.
- Исправлен часовой кэш скриптов/экономики веб-версии: новая ревизия в HTML и no-cache для кода.

## Исправления приёмки M

- Дневные окна по Москве, не раньше фактического старта акции; сегодняшний день не считается закрытым.
- Неполный Finance/неисправный курсор страницы не создаёт полное покрытие и «нулевые продажи».
- Нулевая и отрицательная известная выплата WB не подменяется формулой.
- В дневной детализации возврат уменьшает выручку и выплату; хранение не становится продажей 1 шт.
- Текущая себестоимость возвращённого товара условно восстанавливается; налоги/реклама/прочие
  личные расходы — расчёт по текущим настройкам, не восстановленная историческая бухгалтерия.
- Неизвестный прогноз остаётся null, пересекающиеся акции исключены из общих выводов без двойного счёта.
- Ноль остатков — только наблюдаемый; отсутствие SKU в ответе не доказывает stockout/FBS=0.
- Сравнение до/после не выдаётся за доказательство причинного эффекта.
- Новый набор `stockHistory` включён в единый J: теперь 18 наборов; старые 17-наборные файлы поддержаны.

## Ограничения и следующий пользовательский тест

1. Получены четыре PNG, **сам файл выгрузки WB не получен**. Прочтён синтетический XLSX,
   созданный специально для теста и явно так названный, не файл владельца. Для проверки
   конкретного экспорта нужен исходный `.xlsx`/`.csv` без пересохранения.
2. Реальная авторизованная страница WB, live API/отправка цен и настоящий Telegram не тестировались.
3. IPC проверялся настоящим кодом регистрации с макетом dialog и настоящими байтами XLSX;
   Windows GUI выбора файла, сборка/установка `.exe` здесь не выполнялись. UI — jsdom, не
   визуальная проверка установленного Electron в Windows.
4. Налоговые параметры — для предварительной юнит-экономики, не декларация. Входной НДС,
   вычеты, налог на прибыль/НДФЛ ОСНО и полный расчёт УСН «доходы минус расходы» не автоматизированы.
   Правильность своего режима и уменьшения взносов нужно подтвердить с бухгалтером.
5. Для проверки новой версии обновите исходники и перезапустите приложение. Старый собранный
   `.exe` не меняется от git pull — его нужно пересобрать. В вебе при первом обновлении — Ctrl+F5.
