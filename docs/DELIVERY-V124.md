# Приёмка версии 1.2.4 — нижний блок управления сайдбаром

Дата отчёта: 2026-11-19.

## Что изменено

- Кнопка сворачивания левого меню убрана из шапки рядом с логотипом.
- Внизу сайдбара, над кнопкой «Обновить данные из WB», добавлен единый блок
  управления: слева переключатель темы «Светлая/Тёмная», справа новая кнопка
  сворачивания.
- У кнопки сворачивания новая векторная иконка: панель с разделителем и стрелкой.
  В свёрнутом состоянии стрелка разворачивается в обратную сторону, тема
  остаётся доступной одной иконкой солнца/луны, обновление данных — иконкой ↻.
- Переключатель темы удалён из верхней панели разделов; теперь тема выбирается
  только внизу сайдбара. Логика тем, состояние свёрнутости и навигация не менялись.
