# Поставка v1.3.7 — копирование артикула/SKU и переход в карточку WB

Дата: 2026-11-12.

## Запрос пользователя

Добавить возможность копировать артикул и SKU: рядом с артикулом или SKU при наведении должна появляться кнопка копирования, а также кнопка прямого перехода в карточку товара на Wildberries (пример ссылки: `https://www.wildberries.ru/catalog/1316609739/detail.aspx`).

## Что сделано

Общий механизм в `src/renderer/js/ui.js`:

- `UI.idValue(value, {label, wb})` — значение идентификатора с hover-кнопками: ⧉ «скопировать» и, при `wb:true`, ↗ «открыть карточку на WB». `UI.idsPair(row)` — компактная пара «артикул WB · артикул поставщика» для таблиц.
- `UI.wbCardUrl(nmID)` строит прямую ссылку `https://www.wildberries.ru/catalog/{нм-код}/detail.aspx`.
- Один общий обработчик кликов (перехват на документе): копирование не открывает карточку товара и не срабатывает как клик по строке таблицы. Копирование — Clipboard API, для веб-режима по http в локальной сети — запасной путь через временный `textarea`; после успеха кнопка на 1,2 с показывает ✓ и всплывает тост «Скопировано: …».
- Кнопка ↗ открывает карточку через `API.openExternal` (в Electron — с проверкой «только HTTPS-адреса Wildberries», в вебе — новая вкладка).

CSS (`styles.css`, класс `.idbtn`): кнопки скрыты (`opacity: 0`) и появляются при наведении на значение или при фокусе с клавиатуры; на сенсорных устройствах (`hover: none`) полупрозрачны постоянно.

Где появились кнопки:

- **Репрайсер, таблица товаров**: «SKU / nmID» (копирование + ↗), «Арт.» поставщика (копирование), «Баркод» (копирование; при нескольких баркодах копируется основной), отдельная колонка «Артикул продавца», таблицы «Конкуренты» и массовых параметров.
- **Карточка товара**: бейджи «нм-код» и артикула поставщика в шапке (копирование + ↗).
- **Себестоимость** (таблица и редактор товара), **Экономика**, **Панель**, **Акции WB** (каталог и предпросмотр загруженного файла), **Отчёты** — пара «артикул WB · артикул поставщика» в строке товара.
