# Поставка WB Price Manager 1.1.0

Дата локальной проверки: **19 ноября 2026 года**.
Базовый коммит исходной версии: `9f19f096f4e4d9a9a44abe0bcf37de21df062ee4`.
Версия пакета: `1.1.0`.

## Что входит в обновление

- Рабочее место v4: репрайсер, акции WB, стратегии, настройки, СПП из официальных
  заказов/продаж, ABC за 30/90/180 закрытых дней и лесенка буста.
- Явное локальное сохранение: ввод сначала находится только в памяти окна.
  Запись выполняют кнопки «Сохранить», «Сохранить и закрыть» или «Сохранить все»;
  крестик, фон, Escape и обычная отмена не сохраняют. Сохранение локальных настроек
  не отправляет цены в WB и не включает автоматику без отдельного подтверждения.
- Исправления независимого аудита A-01–A-07, B-01–B-05 и C-01:
  - статистика WB читается по `saleID`, `priceWithDisc`, `forPay` и отменам заказов;
  - возвраты неттятся в P&L и дневной динамике, известный нулевой `forPay` не
    заменяется расчётным значением;
  - показаны обе прибыли — без списания себестоимости возвратов и со списанием
    возвращённой себестоимости;
  - себестоимость хранится как `costEntered` в валюте закупки и производный
    `costPriceRub` в рублях, повторное сохранение не конвертирует сумму повторно;
  - поддерживаются корректные трёхбуквенные пользовательские валюты и их курсы;
  - ручные остаток и продажи в день доходят до расчётного контекста, источник
    остатка различает WB, ручной ввод, демо и отсутствие данных;
  - наблюдённый нулевой остаток не исчезает из агрегации;
  - `maxPrice` является жёстким потолком, а невозможный выход из акции явно
    блокируется вместо превышения потолка;
  - акции вне календаря WB показываются как локальные неподтверждённые;
  - при `taxMode: 'none'` доходный налог и НДС равны нулю;
  - Electron усилен: главное окно работает с `sandbox: true`, внешние ссылки
    ограничены HTTPS-доменами Wildberries, IPC проверяет отправителя, CSP не
    разрешает inline-скрипты.

## Что не проверялось

- живой кабинет Wildberries и реальные ответы его API;
- реальные отправки цен, акций и размеров в WB;
- доставка Telegram;
- запуск Windows GUI, установленный или подписанный EXE;
- автоматическое reconciliation частично принятых WB пачек;
- восстановление резервной копии как отдельная ручная проверка на Windows.

Все сетевые проверки выполнялись на синтетических ответах, моках транспорта и
изолированных демо-данных. Запросов на изменение цен в реальный WB не было.

## Сборка Windows

В этой среде EXE не собирался. На Windows используйте:

```text
npm ci
npm test
npm run dist
```

или `Собрать EXE (Windows).bat`: скрипт ставит зависимости через `npm ci`,
запускает `npm test` и останавливает сборку при провале проверок. Подробности —
в `docs/BUILD.md`. Пользовательский профиль и данные кабинета при обновлении
удалять нельзя.
